Final Project Principle

Syn is not a chat application.
Syn is not another coding agent.
Syn is not a file browser with a search box.
Syn is the unified agent memory environment and searchable memory infrastructure for AI coding agents.

Its purpose is to make every previous session, archive, and craftable memory accessible across harnesses through a single, fast, reliable retrieval engine and interactive terminal.

An agent or user should be able to execute commands directly or ask:

/locate Find the implementation decision we made about authentication in the previous project.

Syn searches the archives and the Memory Vault (brain/), identifies the relevant session or file, retrieves the exact context, and returns it instantly.

Capabilities

/locate Search

Search across all indexed sessions and the Memory Vault with ranked results, snippets, and filters (harness:, date:, role:, brain:).

Memory Vault (brain/)

An Obsidian-style markdown vault. Craft memories with /reflect, /meditate, /ruminate, /plan, and /review.

MCP Server

Programmatic access via syn_* MCP tools over stdio. No network calls Ã¢â‚¬â€ local-only.

Cross-Harness

Adapters for Copilot, Codex, Cursor, Cline, Continue, Zed, Aider, Gemini CLI, Pi, T3, and more.

Desktop App

Electron UI for humans to explore, search, and manage sessions. Search bar + terminal column.

Privacy First

Read-only access to original files. Secret redaction at index time. Local index, never uploaded.

Install

Install Syn from a prebuilt installer (recommended) or run from source:

# Option 1: Prebuilt installer
# Download from https://github.com/xen38/Syn/releases
# Run the installer for your platform (.exe, .dmg, or AppImage)

# Option 2: Run from source
git clone https://github.com/xen38/Syn.git
cd Syn
npm install
npm start

Then register and index your harness directories via MCP tools:

node mcp-server.js

syn_add_harness <directory>
syn_index_all
syn_search <query>
