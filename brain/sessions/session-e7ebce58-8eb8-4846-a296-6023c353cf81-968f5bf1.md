The fix is complete. Here's a summary:

## Root Cause

The Brain Vault window's graph canvas was collapsing to 0×0 because `.brain-vault-body` had `display: flex; flex-direction: column` but **no `height: 100%**`. Without a height on the body, the entire flex chain collapsed:

```
body (auto height) → content (flex:1 → 0) → tab-content.active (flex:1 → 0) 
→ graph-wrap (flex:1 → 0) → graph-container (flex:1 → 0) → canvas (100% of 0 → 0)
```

With a 0×0 canvas, all graph nodes were positioned at (0,0) and invisible. The window controls were also effectively non-interactive since elements had zero dimensions.

## Fix Applied

**`renderer/style.css`** — Added `height: 100%` to `.brain-vault-body`:

```css
.brain-vault-body {
  display: flex;
  flex-direction: column;
  height: 100%;   /* ← added */
}
```

This lets the flex chain resolve properly: the body fills the 900×700 window, and the canvas gets real dimensions so nodes render at their computed positions around the center.
